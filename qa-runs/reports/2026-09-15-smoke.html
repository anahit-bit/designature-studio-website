High #F1 broken-flow

Unknown URLs redirect to the home page; no 404 page exists.

global (tested /this-does-not-exist-zzz and /faq/this-does-not-exist-zzz)endesktop|mobile
View details

Detail

src/App.tsx line 201 declares &lt;Route path=&quot;*&quot; element={&lt;Navigate to=&quot;/&quot; replace /&gt;} /&gt;. A visitor with a mistyped or stale link lands on the home page with no message, and the URL bar is rewritten to /. Production marks unknown paths noindex in the server render (SEO-NOTES.md), which contains the SEO cost, but the visitor experience is the same. The skill's fixed pass requires a 404 page, so severity is high by rubric; the product impact is moderate.

Evidence

Local run: both URLs returned 200 and rendered H1 'Bring us a space. We'll bring it to life.' Screenshot not needed; the App.tsx line is the proof.

Steps to reproduce

  1. Open /anything-that-does-not-exist. 2. Observe redirect to / with no notice.
High #F2 performance

index.html loads the Tailwind Play CDN and defines the brand tokens there; the compiled Tailwind 4 build does not carry them.

globalendesktop|mobile
View details

Detail

index.html line 58 loads https://cdn.tailwindcss.com and lines 63 to 80 set tailwind.config with font-display (Cormorant Garamond), font-body (Montserrat), tracking-architectural and the shake animation. src/index.css has no @theme block, so those classes exist only if the CDN script runs. The site is already built with Tailwind 4 through @tailwindcss/vite, so every page ships two Tailwind engines, and the Play CDN is documented by Tailwind as not for production. When the CDN is blocked (ad blockers, corporate networks, offline, this sandbox) every page throws tailwind is not defined 8 times and headings fall back to the default sans font. Fix: move the four tokens into an @theme block in src/index.css, delete the script and the inline config, then compare screenshots.

Evidence

Page errors captured on every route: 'tailwind is not defined' x8. index.html lines 58 to 80. grep @theme src/index.css returns nothing.

Steps to reproduce

  1. Block cdn.tailwindcss.com in the browser (or go offline after the first paint). 2. Reload any page. 3. Headings render in the fallback font and the console shows the error.
